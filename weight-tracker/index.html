    Log with Siri

    Say “Hey Siri, log weight”, then say the number when Siri asks. Set it up once in the Shortcuts app:

    1. Open Shortcuts, tap + and name the shortcut Log weight.
    2. Add Ask for Input. Set the type to Number and the prompt to “What's your weight?”
    3. Add URL. Paste the link below, then insert Provided Input right after w=.
    4. Add Open URLs, then tap Done.

    Siri opens this page in Safari and saves the weight there. Use the app in Safari, or from a Home Screen icon added with Open as Web App turned off. An icon added as a web app keeps separate entries that Siri can't reach.

    You're using the Home Screen web app now, so Siri's entries won't show up here. To move your entries, tap Export CSV here, then Import CSV in Safari.
